# SocialBlade Creator Stats for Gemini CLI

Subscriber and follower history, 7/30/90-day gains and spike dates for YouTube, TikTok, Instagram and Twitch creators.

This extension connects Gemini CLI to the hosted MCP server [SocialBlade Creator Stats](https://mcpize.com/mcp/socialblade-creator-stats). It reads public pages only and needs no login or cookies for the source itself.

## Install

```
gemini extensions install https://github.com/benthepythondev00/socialblade-creator-stats
```

Gemini CLI asks for your MCPize API key once and keeps it in the system keychain.

## Get a key

1. Open https://mcpize.com/mcp/socialblade-creator-stats and subscribe. The Free plan needs no card.
2. Copy the API key shown on the server page.

## Try it

- "Get SocialBlade stats for https://www.youtube.com/@mkbhd and show the last 15 days of subscribers."
- "Show the top 10 YouTube channels in gaming."
