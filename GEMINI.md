# SocialBlade Creator Stats

Subscriber and follower history, 7/30/90-day gains and spike dates for YouTube, TikTok, Instagram and Twitch creators.

Use the tools of the `SocialBlade Creator Stats` MCP server when the user asks for this data. Ask for a small `limit` first and widen it only when asked. If a call answers 401, the MCPize API key is missing or expired: tell the user to run `gemini extensions config` for this extension.
